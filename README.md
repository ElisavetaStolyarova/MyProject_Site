# MyProject Site 🌐

Это мой личный сайт-визитка, разработанный для демонстрации моих навыков, проектов и профессионального опыта. 

---

##  Цель проекта

Создать удобную и эстетичную платформу для презентации моих компетенций как разработчика. Сайт позволяет потенциальным заказчикам и работодателям быстро ознакомиться с моим стеком технологий и примерами выполненных работ.

##  Что внутри?

*   **Обо мне:** Краткая биография, мои профессиональные интересы и цели.
*   **Портфолио проектов:** Галерея реализованных приложений.
*   **Контактная форма:** Возможность связаться со мной напрямую через сайт.

##  Технологический стек

При создании сайта использовались:
*   **Frontend:** HTML5, CSS3 (современная верстка, Flexbox/Grid).
*   **Дизайн:** Адаптивный дизайн, обеспечивающий корректное отображение на смартфонах, планшетах и мониторах.
*   **Логика:** JavaScript — для интерактивных элементов и плавной навигации.

##  Как реализована структура

1.  **Модульность:** Сайт разделен на логические секции, что позволяет легко обновлять информацию о новых проектах.
2.  **Производительность:** Оптимизация изображений и чистота кода для быстрой загрузки страниц.
*   **Архитектура:** Использование семантических тегов HTML для лучшего SEO-продвижения и доступности.
*   **Адаптация:** Наличие смены темы с темной на светлую (Dark mode).

##  Представленные проекты

На сайте можно найти подробную информацию о моих ключевых работах, таких как:
*   **Fitness Booking App:** Мобильное приложение на Android с системой ролей и защищенной БД.
*   **Recipe Manager:** Консольное приложение на C# с глубокой проработкой логики безопасности.
*   **Booking Service:** Веб-сервис для записи на услуги.
